OpenHarness Memory System

持久化项目知识层 — 跨会话上下文保留与检索

模块架构

  • • paths.py: 零依赖，路径解析
  • • types.py: 零依赖，数据模型
  • • scan.py: 扫描 + frontmatter
  • • search.py: token 匹配搜索
  • • manager.py: CRUD + 并发安全
  • • memdir.py: Prompt 片段生成

存储策略

  • • ~/.openharness/data/memory/
  • • SHA1[:12] 哈希消歧同名项目
  • • resolve() 消除符号链接
  • • exclusive_file_lock (fcntl.flock)
  • • atomic_write_text (temp+fsync)
  • • MEMORY.md 索引入口

两级注入机制

  • • Layer 1: load_memory_prompt()
  • - 每次对话注入
  • - MEMORY.md 索引 (≤200行)
  • • Layer 2: find_relevant_memories()
  • - 仅当 memory.enabled=True
  • - token 匹配 (meta ×2.0 + body ×1.0)
  • - 匹配文件全文 (≤8000字符)
